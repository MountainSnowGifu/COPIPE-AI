# v2/src/tools/ — CLIエージェントのツール群

`v2/src/tools/` には計25個のビルトインツールが登録されています。
[registry.mjs](../v2/src/tools/registry.mjs) が全ツールを `Map` で管理し、`validateInput → call` の流れで統一ディスパッチします。MCPサーバーのツールも同じインターフェースでラップして動的登録できます。

---

## ファイルシステム操作

| ツール         | ファイル            | 説明                                                                         |
| -------------- | ------------------- | ---------------------------------------------------------------------------- |
| `Read`         | `read.mjs`          | ファイル読み込み（読んだファイルをトラッキング）                             |
| `Write`        | `write.mjs`         | ファイル新規作成・上書き                                                     |
| `Edit`         | `edit.mjs`          | ファイルの文字列を完全一致で置換。事前に `Read` 済みであることが必須         |
| `MultiEdit`    | `multi-edit.mjs`    | 複数の置換を一括実行                                                         |
| `Ls`           | `ls.mjs`            | ディレクトリ一覧表示                                                         |
| `Glob`         | `glob.mjs`          | ワイルドカードパターンでファイル検索（`*`, `**`, `?` 対応）                  |
| `Grep`         | `grep.mjs`          | ripgrep / grep でファイル内容を正規表現検索。`-A/-B/-C` コンテキスト行も対応 |
| `NotebookEdit` | `notebook-edit.mjs` | Jupyter Notebook セルの編集                                                  |
